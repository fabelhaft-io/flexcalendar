### My own checks

- **Gap claims, independently** (my own script over the installed packages, not the probe code): both `libsodium-wrappers` and `-sumo` 0.8.4 (libsodium 1.0.22) export only the HKDF constants (`crypto_kdf_hkdf_sha256_BYTES_MAX`, `…_BYTES_MIN`, `…_KEYBYTES`, and the sha512 ones) and no HKDF function; `crypto_auth_hmacsha256*` is in sumo only; `crypto_pwhash` is in sumo only; every primitive the epic names is a function in both builds; 158 functions in standard, 260 in sumo (the doc's "102 sumo-only" holds).

## Brief for run 1

The requirement is in `docs/epics/E12-crypto-core.md` § E12-R02; ADR 0002 § Consequences says to verify the libraries rather than assume them, and D-17 says Argon2id is not needed. **This is a check, not the library**: no code in `packages/crypto_dart/` or `packages/crypto-ts/`, no `spec/crypto.md` (that is E12-R01, next). Writable paths: `docs/verification/` and `infra/crypto-libs-check/`.

### What to deliver

1. **Probes** under `infra/crypto-libs-check/`, one per target, each a self-contained project that is run once and records what it saw:
   - `flutter/` — a minimal Flutter app (Flutter 3.47.6, the pin in `apps/mobile/.fvmrc`; Android only, minSdk 26 as `apps/mobile`) depending on `sodium_libs`, with an `integration_test/` that runs on an Android emulator. The reviewer runs it on the host's emulator (`flutter test integration_test -d <emulator>`); you can't.
   - `dart_vm/` — a Dart console program for the Dart VM (the Dart 3.13.5 inside that Flutter). `sodium_libs` is a Flutter plugin; on the plain VM the binding is the `sodium` package over a system `libsodium` loaded with `DynamicLibrary.open`. Find out which is right, say so in the doc, and record which `libsodium` it loaded (the dev host has `/usr/lib/libsodium.so.26`).
   - `node/` — a Node 24 ES module that loads `libsodium-wrappers` (and, only if a primitive is missing there, `libsodium-wrappers-sumo`) and runs the same checks. Its own `package.json` with exact versions; it is **not** a pnpm workspace member, so the root `pnpm-workspace.yaml`, `package.json` and `pnpm-lock.yaml` stay untouched, and no `node_modules/`, `.dart_tool/`, `build/` or lockfile of a probe is committed (add a `.gitignore` inside `infra/crypto-libs-check/`).
2. Each probe checks **every** primitive the epic names, by calling it, not by testing that a symbol exists:
   - XChaCha20-Poly1305-IETF AEAD: encrypt then decrypt with associated data, and a flipped tag byte or AAD byte fails to open;
   - `crypto_box_seal` / `crypto_box_seal_open` (X25519 sealed boxes): round trip, and the wrong recipient key fails;
   - Ed25519 detached sign/verify: round trip, and a flipped message byte fails;
   - HKDF-SHA-256 **and** `crypto_kdf` (BLAKE2b `derive_from_key`): both, because the wire spec (E12-R01) picks one. For HKDF, check against the RFC 5869 test case 1 (expected OKM `3cb25f25faacd57a90434f64d0362f2a2d2d0a90cf1a5a4c5db02d56ecc4c5bf34007208d5b887185865`); if a library has no HKDF, say so and whether HMAC-SHA-256 is there to build it from;
   - `randombytes_buf`, and the library's own version string (`sodium_version_string`).
   Where the same fixed inputs go into the three probes, the outputs must be byte-identical: use fixed keys, nonces and messages, and print hex, so the doc can compare the three columns. Sealed boxes and the RNG are randomised; compare their round trips only.
3. `docs/verification/crypto-libs-2026-10-12.md` (rename it to the day you finish if that differs): the versions (package, the libsodium inside it, Flutter, Dart, Node, the emulator's API level and ABI), the commands run with their output, the comparison table, and the **gaps**: what a library lacks, what the non-sumo `libsodium-wrappers` build lacks next to sumo for these primitives (the epic's note), and a recommendation for E12-R01/R03 (sumo or not, HKDF or `crypto_kdf`). The rows for the Android emulator are left for the reviewer to fill in with the output of the run: write the table with those cells marked `pending — reviewer runs on the emulator`, and the exact command beside it.
