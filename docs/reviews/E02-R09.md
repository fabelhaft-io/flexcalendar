### Scope, facts, invariants

- All 25 files are inside `--paths`. No secrets are committed. `.gitignore` covers state and `.terraform/`, and the provider lockfile is tracked.
- **Unrequested edit:** `infra/README.md`'s existing table and `*user*` were reformatted by Prettier. That's churn only, with no content change.
- The dev password defaults change to `Development1!` (13 characters) so they meet the 12-character policy. That is needed, and it's documented. Old volumes need `make dev-reset`.
- **D-11 / `02` § Backups and recovery:** "no durable state on local disk outside Postgres". The OpenTofu state is on a local volume here, and the README tells staging and production to keep it on "private state storage". That is outside the one cluster that pgBackRest backs up. The state also holds the helper's PAT.
- No content crypto in `server/**`, and no event content. `token.mjs` uses `node:crypto` only to verify the JWT signature, in `infra/`.

## Fix requests (review 2)

1. **Remove the drift.** Drop the `android {}` block from `zitadel_application_oidc.android`: it only carries App Links signing fingerprints, which the private-use redirect scheme doesn't use, and Zitadel doesn't store it empty. Update `tests/auth.tftest.hcl` and the README to match.
2. **Keep the state in Postgres, with the instance it describes** (D-11). Use OpenTofu's `pg` backend with a schema of its own in Zitadel's database, so the state and the instance are created, backed up, restored and torn down together:
   - `make dev-reset` then removes it with the rest;
   - dropping Zitadel's database drops it too;
   - a restore brings back matching state.
   Remove the `zitadel-state` volume and the local backend. The connection string comes from the environment, like the DSN.
3. **Prove both teardowns on the stack procedure in the README:**
   - `make dev-reset && make dev && make seed && make seed && make zitadel-plan` exits 0 when run **twice in a row**;
   - dropping only the `zitadel` database, then `make dev && make seed && make zitadel-plan`, exits 0.
   List both for the reviewer.
4. **Build only the config image in `make seed`:** `$(COMPOSE) --profile seed build zitadel-config`, then `run --rm` without `--build`, so a seed never recreates the API and CalDAV containers.
5. **Revert the reformatting of the existing `infra/README.md` text.** Keep the new section.

Change nothing else.
