### Auth surface, for the human approval (`agent+review`)

- **Android** (`de.flexcalendar.app`): native, public client (auth method NONE), OIDC 1.0, response type CODE.
  - Grants: authorization code and refresh token only.
  - **PKCE is enforced when used, but not required.** Tested on the real stack with a copy of the helper (S256):
    - a challenge with the right verifier gets a token;
    - a challenge with no verifier gets HTTP 400 at the token endpoint;
    - a challenge with a wrong verifier gets HTTP 400;
    - **no challenge and no verifier gets a token.**
    So an intercepted code from a flow that used PKCE can't be exchanged. But Zitadel v4.16 does not require PKCE from this public client, which OAuth 2.1 recommends. Provider 3.8.7 offers no switch for it: `tofu providers schema -json` lists 24 attributes for `zitadel_application_oidc`, none about PKCE, and `use_pkce` exists only on the external-IdP resources (`zitadel_idp_oauth`, `zitadel_idp_oidc` and their org variants). Follow-ups: E10-R02 must always send S256, and E08-R08 should look for a server-side switch at each upgrade.
  - Access tokens are JWTs.
  - Redirect `de.flexcalendar.app:/oauth2redirect`; post-logout `de.flexcalendar.app:/logout`.
  - Clock skew 0, dev mode off, no extra origins, role and userinfo assertions off, no App Links fingerprints.
- **API** registration: auth method PRIVATE_KEY_JWT, with no key or secret provisioned. It is a registration, not a credential.
- **Project**: role assertion and role check off, project check off.
- **Passwords**: at least 12 characters, no composition rules, no expiry.
- **Lockout**: after 10 failed passwords; no OTP lockout.
- **Login**: username/password on, registration off, external IdPs off. TOTP and U2F as second factors; passkeys allowed; MFA not forced. Reset link hidden. Unknown-username hiding off, domain discovery on.
- **Lifetimes**: access and ID tokens 12 h; refresh 30 d idle, 90 d absolute; password check 10 d; second factor 18 h; multi-factor 12 h; MFA-setup skip 30 d.
- **Token helper**, local and staging only:
  - machine user `calflex-token-helper` with a JWT access-token type and no secret or key;
  - instance role **`IAM_LOGIN_CLIENT`**, which can create sessions for any user;
  - a PAT that expires 2030-01-01 and lives only in the OpenTofu state;
  - production has no account, role or PAT.
