## Traps checked on postgres:18-alpine (2026-10-09)

- Postgres 18 lists `NOT NULL` in `pg_constraint` (`calendars_mode_not_null`). A test that lists the table's constraints must expect it, or filter on `contype = 'c'`.
- **Which check fires depends on the name.** Postgres evaluates check constraints in name order, and `calendars_meta_envelope_check` sorts before `calendars_mode_private_only_check`. `shared` without an envelope violates only the private-only check. `shared` **with** an envelope fires the envelope check first. Assert `error.constraint`, not just `23514`, and pick the row that isolates the check under test.
- An unknown label such as `'bogus'` is `22P02` (`invalid_text_representation`), not a check violation.
- A check violation is raised before a unique violation, so a duplicate `caldav_href` on a `shared` row now reports `23514`.
