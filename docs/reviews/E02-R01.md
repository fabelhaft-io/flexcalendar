2. **`apps/mobile/android/README.md`: make the DAVx⁵ line licence-neutral.** "never copy from it into this MIT project" takes the other side of the same contradiction. Say instead that DAVx⁵ is GPLv3, read it for reference only, and check licence compatibility before copying anything (`02` § Android specifics).
3. **`packages/crypto_dart/README.md`: fix the phase number.** "only if Phase 6 mirroring ships" uses ADR 0002's old phase numbering. In the current plan (`04`, ADR 0003) mirroring of Private calendars is the optional **Phase 8** item (E16), extending the Phase 6 adapter. Write "only if the optional Phase 8 mirroring (E16) ships".

Change nothing else. Re-run the same checks and report them.
