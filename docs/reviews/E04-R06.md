Do not touch the offender order the test asserts, except to add the new entry.
2. **INV-03 tests, table-driven over every name the README promises.** One bad case per name, each asserting the exact diagnostic label: the six SQL names; the five `Uuid::uuidN` forms; the five `Uuid().vN()` forms; the five accessors `uuid.v1`, `v3`, `v5`, `v6`, `v7` and `uuid/v7`; the ESM named import (one line and a multi-line one) and the CommonJS `require` form; the six bare tokens.
