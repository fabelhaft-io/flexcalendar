- **From the E12-R02 review, for later requirements:**
  - **E12-R03, E12-R04 (the Dart dependency):** `sodium_libs` is discontinued on pub.dev (`replacedBy: sodium`) and 4.0.1 only re-exports `sodium`; depend on `sodium` 4.1.1+2 directly. It builds libsodium 1.0.22 through a build hook, which `dart run` and `dart test` honour and `dart <file>.dart` does not. ADR 0001 § Libraries says so since PR #98;
  - **E12-R06 (the first `sodium` in the app):** the first Android build of a `sodium` app on the dev host took 446 s and downloaded NDK r28c (`28.2.13676358`) into the Android SDK; plan for that in CI and in a fresh dev setup;
  - **E12-R05 (cross-language vectors in CI) and Phase 5's `packages/crypto-ts`:** the probes in `infra/crypto-libs-check/` are run-once evidence, not gated by `make verify`; their `frozenValues`/`FROZEN_VALUES` are a ready seed for the frozen vectors. Pick sumo only if the spec needs HMAC (or ever Argon2id, which D-17 rules out); the standard build has every primitive the epic names.
